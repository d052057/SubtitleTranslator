Getting started with this template

This page shows once, right after you scaffold a new project. Replace it with your own home page whenever you're ready.

1. Install the template (one time only)

From a PowerShell/cmd prompt in the folder containing this template's source:

dotnet new install .
2. Create a new project from it
dotnet new standalone-angular -o MyNewProject
3. Open and run in Visual Studio 2022

Open the generated .sln file and press F5.

Troubleshooting: "npm start" fails on a new project

Sometimes node_modules ends up incomplete right after scaffolding. Fix with a clean reinstall:

rmdir /s /q node_modules
npm install
ng build
